Hi, I'm Attila. I make developer tools and small games.

Right now I'm building [TerminalGrid](https://github.com/terminalgrid), a tiled terminal manager with built-in AI agents for Windows and macOS. [Download it here.](https://github.com/terminalgrid/releases/releases/latest)

New: [TerminalVoice](https://github.com/terminalgrid/terminalvoice-releases), voice dictation that works in every app. Hold a key, talk, and clean text appears where your cursor is. Speech is transcribed on your computer, and AI formatting uses the model you choose. Windows for now.
